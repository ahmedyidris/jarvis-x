# Google Drive Voice Training Setup

## STEP 1: Create Folder on Google Drive (WEB)
1. Open: drive.google.com
2. Click "New" → "Folder"
3. Name: `Jarvis X - Voice Training`
4. Create subfolders inside:
   - 01-raw-recordings/
   - 02-reference-accents/
   - 03-trained-models/

## STEP 2: Get Folder ID
1. Open the folder
2. Copy ID from URL: https://drive.google.com/drive/folders/[ID]
3. Save the ID

## STEP 3: Upload Files
1. Go to: 01-raw-recordings/
2. Upload your .m4a files
3. Upload Egyptian podcast samples to 02-reference-accents/

# letters

Kids' educational "letter of the day" videos (e.g. "A is for Apple!"). The **only** Phase B vertical where the LLM is allowed to invent content freely — no factual-accuracy constraint, since this is children's content, not a real-world claim.

- **Generator:** `automation/phase-b/content_generator.py`
- **Duration:** 15s (fixed)
- **Known issues:** none tracked separately from [[system-overview]]'s general notes.

See [[add-a-phase-b-vertical]] for how new verticals are built, and [[economic-facts]] for the contrasting fact-constrained pattern.

# Ahmed's writing voice

**This file is Ahmed's to write. Jarvis must not fill it in.**

`PLAN_5` §6.2's ruling is "Your words, Jarvis assists" — Ahmed owns the idea
and the narrative, Jarvis owns everything downstream. A script drafted in a
voice Jarvis invented for him would invert that ruling while appearing to
satisfy it, which is worse than no draft at all.

So `code/content-draft.js` REFUSES to draft while the `<!-- UNFILLED -->`
marker on the first line is still here. Delete that line once the sections
below have real content. Nothing else detects "unfilled" — the marker is the
whole mechanism, deliberately, so there is no clever heuristic to be subtly
wrong about.
